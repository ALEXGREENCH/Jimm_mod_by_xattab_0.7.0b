# Jimm by XaTTaB 0.7.0b

Модификация мобильного ICQ-клиента [Jimm](https://sourceforge.net/projects/jimm/) для телефонов с поддержкой Java ME. Продолжение [Jimm by XaTTaB 0.6.0a](https://github.com/ALEXGREENCH/Jimm_mod_by_xattab_0.6.0a), с сохранением структуры исходников и препроцессора SiJaPP.

Версия **0.7.0b**, целевая историческая сборка — **12 мая 2010 года**.

Имя приложения на телефоне — **J[im]m**, с оригинальным значком и атрибутами Java ME из майских сборок. Сохранены исходные пакеты, ресурсы платформ, авторство Jimm Project и XaTTaB.

Исходное дерево восстановлено предположительно, на базе 0.6.0a и сохранившихся JAR. Авторские пакеты, заголовки файлов и директивы SiJaPP сохранены. Восстановление продолжается; [происхождение изменений и степень соответствия оригиналу](docs/SOURCE-RECOVERY.md) описаны отдельно.

## Возможности

- Список контактов с группами, скрытием пустых групп и сортировкой по активности.
- Статусы и XStatus, определение клиентов и их версий.
- Настраиваемый интерфейс: фон, цвета, прозрачность курсора, заголовка и софтбара, тень шрифта.
- Canvas-формы, всплывающие окна, настройки редактора и подсветки.
- Шаблоны сообщений, выбор смайлов, XStatus и цветов интерфейса.
- Смайлы и анимированные смайлы, история сообщений, счётчик трафика, передача файлов и прокси — подключаемые модули сборки.
- Копирование и объединение фрагментов сообщений, вставка с цитированием; журнал MagicEye.
- Импорт и экспорт настроек в `jimm_options.sav`.

## Сборка

Нужны **Python 3.9+** и **JDK 11–17**. Выполнять из корня репозитория:

```sh
python tools/build_source.py
```

По умолчанию собирается русская версия MIDP2. Выбор телефона и языка:

```sh
python tools/build_source.py --target MOTOROLA --language EN
python tools/build_source.py --target SIEMENS2 --language UA
```

Готовые файлы: `dist/source/Jimm-<TARGET>-<LANG>.jar` и `.jad`.

[Инструкция сборки и параметры модулей](docs/BUILD.md) · [Оригинальные JAR и архивы](docs/ARCHIVE.md)

Унаследованный `build.xml` также оставлен в корне. Для исторической сборки через Ant нужно настроить пути к Java ME SDK и ProGuard; [инструкция исходного репозитория 0.6](docs/BUILD-0.6.md) сохранена отдельно. Этот способ сборки 0.7 пока не проверен.

## Исходники

| Каталог | Содержимое |
|---|---|
| `src` | Исходники Jimm с директивами SiJaPP |
| `src/lng` | Исходные файлы пяти локализаций |
| `res` | Графика, звуки и ресурсы платформ |
| `util` | Препроцессор SiJaPP и задачи обработки языков |

| `preservation`, `reconstruction` | Эталонные сборки и материалы исследования |
