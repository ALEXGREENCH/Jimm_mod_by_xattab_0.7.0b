# Jimm by XaTTaB 0.7.0b — восстановление

Продолжение [репозитория 0.6.0a](https://github.com/ALEXGREENCH/Jimm_mod_by_xattab_0.6.0a) с сохранённой Git-историей. Изменения **0.7.0b от 12.05.2010 перенесены в основной `src`**, с прежними пакетами, осмысленными именами и условиями SiJaPP. Это восстановленные исходники, не найденный авторский архив.

**Сборка из `src` работает для MIDP2, Motorola и Siemens2, на RU, UA, RO, EN и CZ. Полная эквивалентность оригинальному JAR пока не достигнута и не доказана.** Проверенная область и оставшиеся ограничения описаны в [SOURCE-RECOVERY.md](docs/SOURCE-RECOVERY.md).

## Что перенесено

- Canvas-формы и всплывающие окна: `VirtualForm`, `FormChoiceGroup`, `FormItem`, `FormIcon`, `VirtualAlert`; существующие экраны переведены на них.
- Прозрачность курсора, заголовка и софтбара, тень шрифта, иконки групп, скрытие пустых групп, сортировка по активности, положение XStatus.
- Настройки 0.7 с правильными номерами RMS, импорт/экспорт `jimm_options.sav`, сброс, подтверждение выхода, запоминание смайла, настройки редактора и подсветки Nokia.
- Распознавание клиентов и их версий, новые capabilities, расширенные статусы при приёме и отправке, обновлённые идентификаторы клиентов.
- Ресурсы майской сборки и изменения пяти языковых таблиц. Короткие ключи разных локализаций сопоставлены по месту использования в байткоде.
- Удалён прежний встроенный мастер регистрации UIN, отсутствующий в майском эталоне.

Официальная [ветка Jimm 0.7.0](https://sourceforge.net/p/jimm/code/HEAD/tree/branches/0.7.0/jimm/) используется для сверки имён и происхождения общей логики. Числа настроек и особенности XaTTaB проверяются по его JAR: они отличаются от основной ветки.

## Сборка и проверки

Нужны Python 3.9+ и JDK 11–17. Инструменты скачиваются с проверкой SHA-256; WTK и локальный Ant не требуются. Используются **настоящие SiJaPP и LangsTask из `util`**, затем ECJ и ProGuard с CLDC preverification.

```sh
python tools/build_source.py
python tools/build_source.py --target MOTOROLA --language EN
python tools/build_source.py --target SIEMENS2 --language UA
python tools/test_source.py --matrix
python tools/audit_source.py
```

Результат: `dist/source/Jimm-<TARGET>-<LANG>.jar` и `.jad`. Компилируется `src`; классы из оригинального JAR не подмешиваются. Vendor API stubs используются только при компиляции и не попадают в MIDlet.

- **75 837** сравнений с исполнением майского байткода: версии клиентов, исходящие статусы, сериализация и чтение настроек.
- **3 159** наборов capabilities и fingerprints: сравнение клиента, версии, маски capabilities и 11 входящих статусов для каждого набора.
- Запуск MIDP2 в MicroEmulator и открытие/сохранение десяти разделов настроек с RMS в памяти.
- Сборка 15 вариантов и проверка препроцессора при выключенных модулях.

Результаты: [функциональные проверки](preservation/reports/source-tests.json), [сигнатуры и инструкции выбранных методов](preservation/reports/source-bytecode-comparison.json). Совпадение количества классов и успешные тесты не означают полную эквивалентность приложения.

## Архивные материалы

Сохранены все **15 официальных сборок от 12.05.2010**, три приложенных JAR от **28.03.2010**, архивы 0.5.2b и исходников 0.6. Даты проверены по содержимому: [revisions.json](preservation/revisions.json). Адреса загрузок и хеши: [download-provenance.json](preservation/download-provenance.json).

- `src`, `res`, `util`, `build.xml` — основная ветка восстановления 0.7 на базе исходников 0.6.
- `preservation/wayback-originals` — неизменённые майские эталоны; `preservation/originals` — приложенные мартовские сборки.
- `reconstruction/resources` — точные ресурсы каждого эталона и декодированные словари.
- `reconstruction/midp2/src` — отдельная ранняя реконструкция **мартовского** JAR с техническими именами, сохранённая для исследования.
- `python tools/recover.py all` проверяет мартовскую реконструкцию; её [процесс и ограничения](docs/RESTORATION.md) отделены от майской миграции.
