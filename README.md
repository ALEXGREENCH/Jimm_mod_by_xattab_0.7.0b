# Jimm by XaTTaB 0.7.0b — восстановление

Отдельный репозиторий с полной историей [0.6.0a](https://github.com/ALEXGREENCH/Jimm_mod_by_xattab_0.6.0a), оригинальными сборками и восстановленным по байткоду кодом. Работа начата 6 октября 2026 года.

**MIDP2 RU собирается из восстановленных Java-исходников, проходит CLDC preverifier и дифференциальные проверки. Полная эквивалентность оригиналу пока не достигнута и не доказана.** Это реконструкция, а не найденные авторские исходники 0.7.0b.

## Что удалось сохранить

- Три JAR/JAD из предоставленного `jimm-by-xattab-0.7.0b-rus.zip`.
- Все **15 основных сборок** официального сайта из Wayback: RU, UA, RO, EN, CZ × MIDP2, Siemens2, Motorola.
- Дополнительный архив пяти облегчённых сборок **0.5.2b**, не относящихся к 0.7.0b.
- Архив `jimm_0.6.0_src.rar`: внутри действительно исходники 0.6, не 0.7.
- Точные бинарные ресурсы, декодированные языковые таблицы, ссылки происхождения и SHA-256.

Снимок страницы мог исчезнуть, но прямые файлы сохранились в [CDX-индексе Wayback](https://web.archive.org/cdx/search/cdx?url=jimm.im/dload/*&output=json&filter=statuscode:200&collapse=urlkey). Использованные адреса: [download-provenance.json](preservation/download-provenance.json).

## Состояние восстановления

| Вариант | Java-классы | Состояние |
|---|---:|---|
| Приложенный MIDP2 RU | 96 | Исправленные исходники, сборка CLDC 1.0/MIDP 2.0, preverifier, сравнение байткода |
| Приложенный Siemens2 RU | 94 | Декомпиляция для исследования; сборка ещё не восстановлена |
| Приложенный Motorola RU | 94 | Декомпиляция для исследования; сборка ещё не восстановлена |
| Архивные 15 вариантов | 99–101 | Оригинальные JAR/JAD и ресурсы сохранены; отдельная реконструкция впереди |

Приложенные и архивные JAR **различаются кодом**, хотя имеют одинаковую строку версии. У приложенного MIDP2 96 классов, у архивного — 101. EN/CZ также не во всех случаях совпадают кодом с RU/UA/RO. Найденные локализации сохранены как подлинные сборки, а не приклеены к несовместимому набору ключей.

## Сборка и проверка

Нужны **Python 3.9+ и JDK 11+** (`java`, `javac` в PATH; JDK 17 подходит). Ant и установленный Wireless Toolkit для новой сборки не требуются.

```sh
python tools/recover.py all
```

Зависимости скачиваются с Maven Central в `.cache/tools` и проверяются по закреплённым SHA-256. Результат:

```text
dist/reconstructed/Jimm-restored-MIDP2-RU.jar
dist/reconstructed/Jimm-restored-MIDP2-RU.jad
```

Каждый класс компилируется из `reconstruction/midp2/src`. Сборка **не вставляет оригинальные `.class`** в новый JAR. Оригинал используется как эталон, для обратного преобразования имён и копирования ресурсов. MMAPI `VideoControl` предоставлен как интерфейс только для компиляции; API-заглушки в JAR не попадают.

```sh
python tools/recover.py verify    # неизменность оригиналов
python tools/recover.py build     # чистая компиляция и CLDC preverification
python tools/recover.py compare   # отчёт по методам после build
python tools/recover.py test      # дифференциальные проверки после build
python tools/recover.py decompile # исходный вывод декомпилятора; нужен JDK 17
```

Переменные `JAVA`, `JAVAC`, `JAVA17` задают исполняемые файлы. Декомпиляция пишет в `build/recovery/decompiled`, не перезаписывая ручные исправления.

## Проверенный результат

- Все 1147 методов/конструкторов/инициализаторов присутствуют; пропущенных и лишних нет.
- **586/1147** совпадают по символическим инструкциям и таблицам обработчиков, включая 34 абстрактных метода. Среди методов с кодом: **552/1113**.
- Прошли 135 536 дифференциальных проверок: byte/word/dword, запись в обоих порядках байтов, TLV и регистр всех 65 536 UTF-16 code units.
- ECJ компилирует с `-source 1.3 -target 1.1` и библиотеками CLDC 1.0/MIDP 2.0; ProGuard 5.2.1 выполняет preverification без обфускации и оптимизации.

Метрика учитывает opcodes, операнды, локальные переменные, символические ссылки, переходы и обработчики; игнорирует constant-pool indexes, debug-данные и StackMap. Это **не процент функциональной готовности**. Отличия могут быть следствием компилятора; совпадение отдельных методов не доказывает работоспособность всей программы. Сеть, RMS, UI, камера и реальные телефоны пока не прошли сквозные проверки.

Подробности: [сравнение методов](preservation/reports/midp2-bytecode-comparison.json), [тесты](preservation/reports/differential-tests.txt), [процесс и ограничения](docs/RESTORATION.md).

## Файлы

- `src`, `res`, `util`, `build.xml` — унаследованный код/сборка 0.6. [Старая инструкция](docs/BUILD-0.6.md).
- `reconstruction/midp2/src` — собираемый восстановленный код приложенного MIDP2 RU 0.7.0b.
- `reconstruction/siemens2/reference-src`, `reconstruction/motorola/reference-src` — неисправленный вывод декомпилятора.
- `reconstruction/resources` — ресурсы каждой конкретной сборки и UTF-8 JSON словари.
- `preservation/originals` — приложенные JAR/JAD; `wayback-originals` — найденные на сайте.
- `preservation/downloads`, `SHA256SUMS` — архивы и контрольные суммы.
- `tools/recovery` — анализ, преобразование имён, тесты и патч ручных исправлений.

Имена `C_bq`, `m_a_...`, `f_...` сохранены для связи с байткодом. Для 72 классов записаны **предполагаемые** соответствия 0.6; это не оригинальный ProGuard mapping. Для 501 из 551 русских ключей найдено единственное совпадение по тексту со словарём 0.6. Неоднозначные совпадения помечены, переводы не выдумывались.
